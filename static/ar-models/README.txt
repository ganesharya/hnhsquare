# AR 3D Models

Place .glb (WebGL) and .usdz (iOS AR Quick Look) files here.

Naming: {product_id}.glb and {product_id}.usdz

Example:
- 1.glb (Royal Oak Main Door)
- 1.usdz (Same door for iOS)

To generate:
1. Export 3D models from Blender / SketchUp / Revit
2. Convert to .glb using Blender or online converters
3. Convert to .usdz using Apple's usdzconvert tool
4. Place files here with matching product IDs
